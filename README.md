# End-to-End-Azure-Data-Engineering-Project
### 🌍 Daily Global Capitals Weather Data — 2025

This dataset provides **daily weather summaries for national capital cities worldwide**, automatically updated each day using the **Open-Meteo API**.

Each record contains information about:

- Temperature extremes
- Precipitation totals
- Wind data
- Daylight and solar radiation

Each row represents **one capital city on one date**, making the dataset suitable for **time-series analysis, climate monitoring, and data engineering projects**.

---

#### 🔄 Update Process

The dataset is generated by a **Kaggle Notebook scheduled to run daily (~06:00 UTC)**.

Each execution performs the following steps:

1. Fetches **yesterday’s weather data** from the Open-Meteo API
2. Appends the new data to the **historical dataset**
3. Publishes a **new dataset version**

Note:

- No raw or intermediate files are stored
- Only the cleaned output files listed below are included

---

#### 📁 Dataset Files

| File | Description |
|-----|-------------|
| `history.parquet` | Full time-series of daily weather observations for all capitals (one row per city × day) |
| `history_latest.csv` | Snapshot of the most recent day for quick preview |
| `capitals_clean.parquet` | Reference table of capitals with ISO country codes and coordinates |

---

#### 🧾 Dataset Schema  
*(for `history.parquet` and `history_latest.csv`)*

| Column | Type | Units | Description |
|------|------|------|-------------|
| `date` | string (YYYY-MM-DD) | — | Observation date (UTC) |
| `country` | string | — | Country name |
| `country_alpha2` | string | — | ISO-3166-1 alpha-2 country code |
| `capital` | string | — | Capital city |
| `lat`, `lon` | float | degrees | Geographic coordinates |
| `temp_min_c` | float | °C | Minimum temperature |
| `temp_max_c` | float | °C | Maximum temperature |
| `temp_mean_c_approx` | float | °C | Approximate mean temperature |
| `app_temp_min_c` | float | °C | Minimum apparent temperature |
| `app_temp_max_c` | float | °C | Maximum apparent temperature |
| `precip_mm` | float | mm | Total precipitation |
| `rain_mm` | float | mm | Rainfall amount |
| `snow_mm` | float | mm | Snowfall amount |
| `windspeed_10m_max_kmh` | float | km/h | Maximum wind speed |
| `windgusts_10m_max_kmh` | float | km/h | Maximum wind gust |
| `wind_dir_dom_deg` | float | degrees | Dominant wind direction |
| `sunshine_duration_s` | float | seconds | Sunshine duration |
| `daylight_duration_s` | float | seconds | Daylight duration |
| `shortwave_radiation_MJ_m2` | float | MJ/m² | Daily solar radiation energy |
